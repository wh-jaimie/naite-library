엄마표영어 가이드 #4

보드북·페이퍼백·하드커버,
영어책 판본 고르기

같은 책인데 왜 이렇게 여러 개예요?

안녕하세요, 영어책육아 메이트 나이테예요.

영어책을 검색하면
같은 제목인데 보드북, 페이퍼백, 하드커버…
여러 개가 나와서 당황하셨죠?

같은 이야기를 담은 책이 여러 가지 형태로 나와요
아이 나이와 쓰임에 맞춰 고르시면 돼요 ^^

판본 한눈에 보기

판본이런 책이에요이럴 때 좋아요
보드북표지와 속지가 모두 두꺼운 판지예요책을 물고 던지는 아기 때
페이퍼백얇은 종이 표지, 가볍고 비교적 저렴해요많이 사서 많이 읽힐 때
하드커버단단한 표지, 튼튼하고 오래가요오래 두고 볼 책, 선물용
조작북플랩·팝업·촉감·소리 같은 장치가 있어요책에 처음 흥미를 붙일 때
빅북여럿이 함께 보도록 크게 만든 책이에요여러 아이와 함께 볼 때

조작북 종류

  • 플랩북: 덮개를 들추면 숨은 그림이 나와요 (예: Dear Zoo)
  • 촉감책: 손으로 만져보는 재질이 붙어 있어요 (예: Dear Santa 마지막 페이지)
  • 팝업북: 펼치면 그림이 솟아올라요
  • 사운드북: 버튼을 누르면 소리가 나요

조작북은 아이 손을 많이 타서 금방 망가지기 쉬워요
그래서 중고나 대여보다는
새 책으로 구하시는 걸 추천해요

판본 고를 때 확인할 것

하나, 보드북판은 글이 줄었을 수 있어요
원래 그림책을 보드북으로 다시 낼 때
글을 줄이거나 바꾸는 경우가 있어요
스터디나 음원에 맞춰 읽으실 거라면
같은 판본인지 확인해 보세요

둘, 크기가 다른 판도 있어요
같은 책이 원래보다 작은 판형으로도 나와요
들고 다니기엔 좋지만 그림이 작아져요

셋, CD·세이펜 판이 따로 있어요
책만 있는 판, 책+CD 판, 세이펜으로 찍으면 소리가 나는 판이
따로 나오기도 해요 (→ 가이드 #6)
